Config 파일 만들기
지금 화면 그대로(피벗 위치, 확대, 각도)를 새 initial_camera로 넣은 config.json을 만듭니다. up_vector, SH, 텍스처 등 나머지 값은 그대로 유지됩니다 - 여긴 카메라만 바꿉니다.

만든 파일을 번들 폴더의 기존 config.json에 덮어쓰면, 그게 새 기본 시점이 됩니다 - 이후엔 평소 쓰던 뷰어를 그대로 쓰면 됩니다.

file://로 열면 번들을 못 불러옵니다. python3 -m http.server 등으로 서빙한 주소로 여세요.
