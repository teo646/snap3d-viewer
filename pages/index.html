snap3d

Photograph an object from every angle and snap3d fits the images into a single .snap3d bundle. One line of script embeds a live, turnable view of it in any web page.

create bundle https://github.com/teo646/snap3d
.snap3d config.json  ·  mesh.glb  ·  sh.ktx2  ·  height.ktx2
embed in any page one canvas, one script tag 
<canvas id="viewer" style="width:100%;height:480px"></canvas>
<script src="https://teo646.github.io/snap3d-viewer/dist/viewer.js"></script>
<script>
  new Snap3dViewer(viewer, '');
</script>
starting…
drag to orbit   wheel to zoom   R to reset

Or as a module

import { Snap3dViewer } from 'https://teo646.github.io/snap3d-viewer/dist/viewer.mjs';

const viewer = new Snap3dViewer(canvas, 'my_run.snap3d/config.json');
await viewer.ready;

The <script> build defines Snap3dViewer as the constructor itself, with the rest of the API on it as statics — Snap3dViewer.OrbitControls, Snap3dViewer.loadBundle, Snap3dViewer.VERSION. The loop is demand-driven either way: it draws while something is changing and stops when the image settles, so a still frame costs nothing to hold.

Requirements

  • WebGL2 — 2D array textures, 16-bit float textures, 32-bit indices.
  • DecompressionStream, for the textures' ZLIB supercompression.
  • Chrome 80+, Firefox 113+, Safari 16.4+. There is no WebGL1 fallback.
