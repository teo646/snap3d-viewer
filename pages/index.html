snap3d

About

Photograph an object from various angles and snap3d fits the images into a single 'snap3d bundle'. A few lines of js script embeds a live, turnable view of the bundle in any web page.

Requirements

  • WebGL2 — 2D array textures, 16-bit float textures, 32-bit indices.
  • DecompressionStream, - the textures' ZLIB supercompression.
  • Chrome 80+, Firefox 113+, Safari 16.4+. There is no WebGL1 fallback.
